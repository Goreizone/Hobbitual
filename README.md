# Hobbitual
Hobbitual – Personal Hobby Tracker

Hobbitual is a web-based hobby tracking application designed to help users develop consistency, build better routines, and monitor their personal growth through the activities they enjoy.

**Hobby Management** – Add, rename, and delete hobbies.

**Daily Check-ins** – Track completed hobbies using an interactive monthly matrix.

**Daily Progress Graph** – Visualize daily hobby completion.

**Monthly Overview**– Review monthly activity and completion statistics.

**Yearly Comparison** – Track monthly check-ins and compare progress throughout the year.
